# 项目计划

## 目标

完成一个可用的六爻起卦网页，支持移动端和 PC，具备：

- 输入问题
- 六次掷铜钱
- 生成本卦、变卦、动爻
- 输出结构化解读
- 调用 DeepSeek 生成个性化解读
- 采用中国古风视觉风格，偏道教、酒红、靛蓝、米白底

## 当前任务分解

1. 清点并适配六爻原始数据
2. 建立 normalized data 层
3. 接入正式结构化解卦展示
4. 接入 AI 个性化解读上下文
5. 重构 UI 视觉与交互节奏
6. 完成用户视角验收与体验修正

## 数据现实情况

- `12_六十四卦.json` 已提供 64 卦主索引
- 当前单卦详解文件共 56 个
- 缺失 `兑宫` 8 卦详解文件
- 项目需要支持“有详解时完整显示，无详解时优雅降级”

## 技术实现策略

- 原始 JSON 不直接给页面消费
- 先用脚本归一化为前端友好的标准数据
- 页面只读取统一结构
- AI 解读由服务端代理调用 DeepSeek

## 验收标准

- 用户可从输入问题一路顺畅到拿到结果
- 六次投掷反馈明确，不迷惑
- 本卦、变卦、动爻信息一眼可读
- 结构化内容与 AI 内容分层，不互相混淆
- 缺失数据不会造成报错或空白页
